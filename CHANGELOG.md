# Changelog

All notable changes to Markdown Viewer are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/) (`0.MINOR.PATCH` until 1.0).

## [Unreleased]

### Added
- A simple website in `docs/` with light and dark app previews, install steps and a feature overview.
- This changelog.
- **Copy source button** in Source view, with copied feedback.
- Tests for ⌘K and the copy button.

### Changed
- Quick Open is an auto-height card with a contextual empty state, and clicking outside closes it.
- The Open folder and Properties buttons are left-aligned.
- Refreshed the README screenshots.

## [0.1.0]

First prototype: a native, read-only GPUI Markdown reader with a folder tree, Quick Open (⌘P), find in rendered text, source view, frontmatter Properties panel, heading outline, back/forward history, light/dark mode, adjustable text size, live reload, Finder "open with" support, and a Finder Quick Look extension.
